# TEMORA ⏳
### تایمر تمرکز مینیمال برای کار عمیق

[English README](README.md) · [مشاهده پروژه](https://jnjal.github.io/temora/)

TEMORA یک تایمر تمرکز مینیمال با ظاهر مشکی و بدون حواس‌پرتی است؛ برای وقتی که می‌خواهی روی یک کار بمانی، زمانت را ثبت کنی و روند تمرکزت را ببینی.

[![Deploy to GitHub Pages](https://github.com/jnjal/temora/actions/workflows/deploy.yml/badge.svg)](https://github.com/jnjal/temora/actions/workflows/deploy.yml)
[![License: MIT](https://img.shields.io/badge/License-MIT-white.svg)](LICENSE)

## ✨ امکانات

- **⏱️ تایمر تمرکز:** ثبت عنوان فعالیت و زمان هدف با انتخاب سریع یا تعیین ساعت و دقیقه دلخواه.
- **⚡ ثبت دقیق زمان:** محاسبه بر پایهٔ timestamp برای کاهش خطا هنگام رفتن به تب دیگر یا خواب سیستم.
- **⏸️ کنترل کامل جلسه:** مکث، ادامه، پایان و لغو جلسه؛ جلسه‌های پایان‌یافته در تاریخچه ذخیره می‌شوند.
- **🔔 اعلان پایان زمان:** نمایش اعلان مرورگر هنگام رسیدن به زمان هدف، در صورت فعال‌بودن اعلان‌ها.
- **🧠 فعالیت‌های اخیر:** ذخیرهٔ نام و مدت فعالیت‌های پرتکرار برای شروع سریع‌تر.
- **📊 آمار تمرکز:** مشاهدهٔ جلسه‌های تکمیل‌شده و زمان تمرکز در بازهٔ هفت‌روزه.
- **🎯 هدف روزانهٔ قابل تنظیم:** تعیین هدف روزانه از ۱۵ دقیقه تا ۱۲ ساعت و مشاهدهٔ پیشرفت نسبت به همان هدف.
- **📝 مدیریت تاریخچه:** ویرایش عنوان و مدت جلسه‌ها یا حذف آن‌ها.
- **🎧 موسیقی و یوتیوب:** پخش پس‌زمینه از طریق پلیر YouTube، پشتیبانی از لینک‌های معمولی، Shorts، Live، Embed و شناسهٔ ویدیو.
- **⏮️ کنترل پلیر:** مکث و ادامه، جابه‌جایی در ویدیو، پرش ۱۵ ثانیه‌ای و دسترسی سریع به سه ویدیوی اخیر.
- **🎛️ تنظیمات شخصی:** کنترل اعلان‌ها، صدای شمارش معکوس، صدای پایان، افکت جشن، حجم موسیقی و هدف روزانه.
- **⌨️ میان‌برهای صفحه‌کلید:** شروع سریع، کنترل تایمر و بستن پنجره‌های باز.
- **🎉 بازخورد پایان جلسه:** صدای پایان و افکت بصری قابل خاموش‌کردن.
- **📲 نصب به‌صورت PWA:** امکان افزودن به صفحهٔ اصلی موبایل و پشتیبانی آفلاین از طریق Service Worker.
- **🖤 رابط مشکی OLED:** پس‌زمینهٔ کاملاً مشکی با تایپوگرافی خوانا و جزئیات مینیمال.

> اطلاعات تنظیمات، تایمر فعال و تاریخچه به‌صورت محلی در مرورگر و با `localStorage` نگهداری می‌شوند؛ در نسخهٔ فعلی همگام‌سازی ابری بین دستگاه‌ها وجود ندارد.

## 🚀 راه‌اندازی در محیط توسعه

### پیش‌نیازها

- [Node.js](https://nodejs.org/) نسخهٔ ۱۸ یا بالاتر
- npm یا Bun

### نصب و اجرا

مخزن را دریافت کن:

```bash
git clone https://github.com/jnjal/temora.git
cd temora
```

وابستگی‌ها را نصب کن:

```bash
npm install
```

سرور توسعه را اجرا کن:

```bash
npm run dev
```

سپس آدرس زیر را در مرورگر باز کن:

```
http://localhost:3000
```

### ساخت نسخهٔ نهایی

برای ساخت خروجی Production:

```bash
npm run build
```

برای بررسی TypeScript:

```bash
npm run lint
```

برای اجرای محلی نسخهٔ ساخته‌شده:

```bash
npm run preview
```

## ⌨️ میان‌برها

| کلید | عملکرد |
|---|---|
| `Space` | مکث یا ادامهٔ تایمر فعال |
| `Enter` | شروع تایمر از صفحهٔ ساخت جلسه |
| `Escape` | بستن پنجرهٔ باز؛ از جمله موسیقی، تاریخچه، تنظیمات یا ساخت جلسه |

رفتار میان‌برها هنگام تایپ در فیلدهای ورودی محدود شده تا با نوشتن متن تداخل نداشته باشند.

## 🌐 انتشار در GitHub Pages

پروژه برای انتشار خودکار با GitHub Actions آماده شده است.

1. مخزن را در GitHub باز کن.
2. وارد **Settings → Pages** شو.
3. در بخش **Build and deployment**، گزینهٔ **GitHub Actions** را به‌عنوان Source انتخاب کن.
4. با هر بار به‌روزرسانی شاخهٔ اصلی، Workflow مربوط به `deploy.yml` می‌تواند برنامه را بسازد و منتشر کند.

آدرس انتشار در مخزن اصلی:

[https://jnjal.github.io/temora/](https://jnjal.github.io/temora/)

وضعیت ساخت و انتشار را می‌توانی در [GitHub Actions](https://github.com/jnjal/temora/actions/workflows/deploy.yml) ببینی.
